语义物体课程学习设计

日期：2026-06-03 ｜ 主线：Teacher semantic RL 训练 ｜ 目标文件： Go2Pvcnn/extension/semantic_course.py、 Go2Pvcnn/extension/semantic_curriculum.py、 Go2Pvcnn/go2_pvcnn/mdp/curriculums.py、 Go2Pvcnn/go2_pvcnn/tasks/teacher_elevation_trajectory_mpc_semantic_env_cfg.py

1. 背景和修正方向

旧设计把 plane_counts / non_plane_counts 解释成 semantic level 数量表，并在碰撞率达标后运行期重建 /World/semantic_course。这个方向过于复杂，也会让 SemanticObstacleCount(small=0, large=0) 在初始 level 0 时导致所有平地语义物体消失。

新方向改为：语义物体在环境初始化时一次性按 terrain row 生成，训练过程中不再删除和重建语义物体。terrain row 本身就是难度，row 越高，语义物体数量和密度越高。

本设计删除旧的 semantic level / runtime rebuild 路线。后续代码中不应再保留 semantic_obstacle_curriculum_level、按 semantic level 取数量、或升级后重建语义 course 的生产逻辑。

2. 设计目标

  • 语义物体数量由 terrain row 决定，而不是由独立 semantic level 决定。
  • plane_counts 和 non_plane_counts 都设置为 10 个难度项，分别对齐 terrain row 0-9。
  • 语义物体初始化后保持静态，不在训练中重建 /World/semantic_course。
  • 平面 env 的 terrain row 升级必须同时满足地形指标和语义碰撞率指标。
  • 非平面 env 的 reset / terrain curriculum 不受语义碰撞率 gate 影响。
  • 语义碰撞率直接使用 semantic_contact_small.data.force_matrix_w 和 semantic_contact_large.data.force_matrix_w，不从 reward 值反推。
  • 配置参数可以直接在 teacher_elevation_trajectory_mpc_semantic_env_cfg.py 中调整。

3. 核心配置

配置类仍放在 Go2Pvcnn/extension/semantic_curriculum.py。任务 cfg 引入后，直接在 TeacherElevationTrajectoryMpcSemanticEnvCfg 中挂载实例。

@dataclass
class SemanticObstacleCount:
    small: int = 0
    large: int = 0


@dataclass
class SemanticObstacleCurriculumCfg:
    enabled: bool = True
    plane_terrain_names: tuple[str, ...] = ("flat",)

    # 10 entries by default, aligned to terrain row 0-9.
    plane_counts: tuple[SemanticObstacleCount, ...] = (...)
    non_plane_counts: tuple[SemanticObstacleCount, ...] = (...)

    center_safety_half_extent_m: tuple[float, ...] = (...)
    min_spacing_clearance_m: tuple[float, ...] = (...)
    tile_margin_m: tuple[float, ...] = (...)

    collision_force_threshold: float = 1.0
    plane_collision_rate_threshold: float = 0.03
    consecutive_success_required: int = 5
参数作用是否已确认
plane_counts 平面地形每个 terrain row 的 small/large 数量。默认 10 项，对齐 row 0-9。 保留
non_plane_counts 非平面地形每个 terrain row 的 small/large 数量。默认 10 项，对齐 row 0-9。 保留
center_safety_half_extent_m tile 中心避让半径。值越小，障碍越可能靠近机器人初始区域。 保留
min_spacing_clearance_m 物体之间额外间距。中心距离必须大于 radius_a + radius_b + min_spacing_clearance_m。 保留
tile_margin_m 物体距离 terrain tile 边界的最小距离。 保留
collision_force_threshold 从 force_matrix_w 判定语义碰撞的力阈值。 保留
plane_collision_rate_threshold 当前所有平面 env 的语义碰撞率小于等于该阈值时，记一次达标。 保留
consecutive_success_required 连续多少次平面碰撞率达标后，允许平面 env 的 row 升级通过语义 gate。 保留
明确不加入 semantic_curriculum_min_plane_episodes、semantic_curriculum_eval_window_episodes、semantic_curriculum_update_interval_steps、require_terrain_ready。语义 gate 只看当前平面环境碰撞率和连续达标次数，并且只影响平面 env 的 row 升级。

这里的每一项对应一个 terrain row，不对应 semantic level。row 越高，物体越多。平面和非平面各有 10 个可调项，便于分别控制同一 row 难度下的语义物体数量。

5. tile 的含义

当前 terrain generator 使用 num_rows=10、num_cols=20、size=(8.0, 8.0)。因此课程地形由 10 x 20 个小地形块组成，每个小地形块就是一个 tile，大小是 8m x 8m。

row = 地形难度 col = 地形类型 tile = terrain_origins[row][col] 对应的 8m x 8m 地形块

语义物体当前就是按每个 tile 生成，路径保持为：

/World/semantic_course/small/row_XX/col_YY/slot_ZZ
/World/semantic_course/large/row_XX/col_YY/slot_ZZ

新设计必须保留这个路径结构，因为 SemanticGlobalContactSensor 和语义 raycaster 都依赖 small/large 根路径下的真实语义物体。

6. 语义碰撞率指标

升级指标不使用 reward manager 的 semantic_contact_collision 数值，因为 reward 会经过阈值、权重、scale、clip 和 dt，无法直接代表真实碰撞率。

直接从两个真实碰撞 sensor 读取：

small_force = semantic_contact_small.data.force_matrix_w large_force = semantic_contact_large.data.force_matrix_w small_collision_env = any(||small_force[env, body, object]|| > collision_force_threshold) large_collision_env = any(||large_force[env, body, object]|| > collision_force_threshold) semantic_collision_env = small_collision_env or large_collision_env

当前所有平面环境的碰撞率：

plane_collision_rate = count(semantic_collision_env and is_plane_env) / max(count(is_plane_env), 1)

如果当前没有平面 env，则语义 gate 视为未启用，不影响非平面 env 的 terrain curriculum。

7. reset / 升 row 逻辑

语义课程不再维护独立 semantic level。它参考 terrain_levels_vel_unitree_rl_lab 的 reset 逻辑，只在 reset 的 env 上决定是否允许平面 env 升到更高 terrain row。

terrain_move_up = distance > terrain_size_x / 2 terrain_move_down = distance < ||command_xy|| * episode_length_s * 0.5 terrain_move_down = terrain_move_down and not terrain_move_up if plane_collision_rate <= plane_collision_rate_threshold: consecutive_success_count += 1 else: consecutive_success_count = 0 semantic_gate_pass = consecutive_success_count >= consecutive_success_required is_plane_env = terrain_types in plane_terrain_names move_up = where( is_plane_env, terrain_move_up and semantic_gate_pass, terrain_move_up, ) move_down = terrain_move_down terrain.update_env_origins(env_ids, move_up, move_down)

这表示：平面 env 必须地形指标通过且语义碰撞率连续达标，才升 row；非平面 env 完全保持原 terrain curriculum 行为。

这个 reset gate 只作用在平面地形 env，不能影响其他地形的升降级。

8. 文件组织

8.1 extension/semantic_curriculum.py

新增配置类和状态类：

  • SemanticObstacleCount：表示一个 terrain row 的 small/large 数量。
  • SemanticObstacleCurriculumCfg：所有可调参数。
  • SemanticObstacleCurriculumState：只保存语义 gate 的 consecutive_success_count 和最近碰撞率统计，不保存 semantic level。

状态类提供：

8.2 go2_pvcnn/mdp/curriculums.py

新增或替换 IsaacLab terrain curriculum term。它应参考当前 terrain_levels_vel_unitree_rl_lab，但对平面 env 的 move_up 增加语义 gate：

def terrain_levels_vel_semantic_plane_gate(env, env_ids, cfg_name="semantic_obstacle_curriculum", ...):
    ...

职责：

  • 从 env.cfg.semantic_obstacle_curriculum 读取配置。
  • 在 env.unwrapped 上创建或读取语义 gate 状态。
  • 通过 terrain.terrain_types 和 terrain 名称判断哪些 env 是平面。
  • 读取 semantic_contact_small/large.data.force_matrix_w 统计当前平面碰撞率。
  • 更新连续达标计数，得到 semantic_gate_pass。
  • 复用原 terrain distance 指标计算 terrain_move_up 和 terrain_move_down。
  • 只对平面 env 使用 terrain_move_up & semantic_gate_pass；非平面 env 使用原始 terrain_move_up。
  • 返回 dict，供 IsaacLab curriculum logging 使用。

8.3 extension/semantic_course.py

修改语义物体生成数量来源。当前 _stage_slots(...) 内部直接使用 stage_layout(stage)，新逻辑改为按 row 取数量：

if semantic curriculum enabled: if terrain_name in plane_terrain_names: counts = plane_counts[min(row, len(plane_counts)-1)] else: counts = non_plane_counts[min(row, len(non_plane_counts)-1)] layout_cfg = base layout cfg else: counts = _STAGE_LAYOUTS[stage]

保留现有 grounding、shape pool、prim path、scale profile override，不改 z 方向贴地逻辑。

9. 生成逻辑和运行期限制

语义物体是 IsaacSim stage 上的静态全局物体，不是每个 env reset 时动态生成的独立对象。新设计要求：

  • 训练启动时一次性根据 row 和 terrain type 生成全部课程物体。
  • 训练过程中不调用 spawn_static_semantic_course() 重建语义物体。
  • 碰撞率达标只影响平面 env 是否允许升到更高 row，不改变已经生成的物体。
  • 非平面 env 的 reset、升 row、降 row 不受语义 gate 影响。
这样可以避开运行期重建 stage 物体、刷新 contact sensor filter、刷新 semantic raycaster mesh 的复杂风险。

10. 兼容性

  • enabled=False 时保持当前 _STAGE_LAYOUTS 行为。
  • 不改变 SemanticGlobalContactSensor 的 small/large 分类方式。
  • 不改变 MPC loss，不改变 low-small 跨越优化逻辑。
  • 不改变 TeacherElevationTrajectoryMpcSemanticEnvCfg_PLAY 不启动 MPC 的要求。
  • 不从 reward 数值推断碰撞率，避免 scale/clip/dt 干扰。
  • 删除旧 semantic_obstacle_levels 动态重建路线，避免和新 row-gate 逻辑并存。
