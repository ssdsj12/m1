# M1 + Panda 滚动 WBC Teacher C1a 设计

## 状态

- 日期：2026-08-18
- 上游阶段：C0 原地模型验证已通过 GPU0 验收
- 当前阶段：C1a 平地低速纵向滚动
- 交互设计：用户已批准
- 实施状态：尚未开始

## 目标

在已经通过 C0 验收的 M1 + Panda 单 articulation 上，实现平地低速前进、停车和倒车，同时让 Panda 在机身坐标系内跟踪小幅、连续、带限的六维末端轨迹。

C1a 继续采用 Xie 等人在 *Prioritized Multi-task Motion Coordination of Physically Constrained Quadruped Manipulators* 中提出的优先级运动分配与全身控制思路。针对 M1 四轮结构，将四足支撑约束改成轮式纯滚动约束，并维持 `balance-first`：接触、动力学、姿态和执行器安全始终高于底盘速度与 Panda 末端跟踪。

C1a 是确定性 Teacher play，不是 PPO 训练，也不是 Student 训练或数据收集阶段。

## 范围

### 包含

- 平地、单环境、GPU0 确定性验证；
- 纵向速度命令 `v_x`；
- 前进、平滑停车和低速倒车；
- Panda 机身坐标系小幅六维带限轨迹；
- 四轮纯滚动、侧向无滑移、摩擦锥和动力学约束；
- 200 Hz WBC/QP 与 50 Hz 运动分配；
- balance-first 降级、诊断和独立 C1a play 入口；
- C0 完整回归验证。

### 不包含

- 横向速度命令；
- yaw rate 或差速转向；
- 坡地、障碍物或轮足模式切换；
- 额外六维外力、负载或域随机化；
- 世界坐标系固定末端任务；
- 抓取、夹爪闭合、物体交互；
- batched GPU QP、Teacher 数据收集、Student 蒸馏或 PPO；
- 实机部署和最大负载测试。

转向属于 C1b；连续随机底盘命令和扩大机械臂工作范围属于 C2；外力和域随机化属于 C3。

## 方案选择

### 采用方案：扩展 C0 的统一动力学 WBC

轮速、接触力、机身平衡和 Panda 跟踪进入同一套动力学优化。C1a 新增滚动接触与滚动 Teacher 模块，并复用 C0 已验证的动力学读取、运动分配、阻抗和安全基础组件。

不采用“C0 WBC 外挂轮速控制”，因为独立轮速控制会与原地 WBC 目标竞争，无法保证轮驱动力、机身响应和 Panda 内部反作用统一满足动力学。

不在 C1a 重写完整滚动 MPC/WBC，因为改动范围过大，也无法有效复用 C0 的验收基础。

## 控制架构

```text
纵向速度时间表 + Panda 机身系六维轨迹
                    ↓
限速度、限加速度命令整形
                    ↓
优先级运动分配（50 Hz）
  P1 Panda 末端轨迹跟踪
  P2 约束下 M1–Panda 运动再分配
  P3 可操作度提升与奇异规避
                    ↓
滚动 WBC/QP（200 Hz）
  P0 动力学、接触、摩擦锥和执行器硬限制
  P1 四轮支撑、机身高度/横滚/俯仰和动态平衡
  P2 纵向底盘速度和四轮滚动关系
  P3 Panda 关节跟踪
                    ↓
q_des[23]、qdot_des[23]、tau_ff[23]
                    ↓
阻抗、安全限幅和单 articulation
```

`sim.dt=0.005 s`，因此 WBC 每个物理步执行。运动分配每四个物理步执行一次。低频目标必须在物理步之间连续插值。

## 纵向命令与课程

C1a 使用固定的 20 秒确定性命令时间表：

```text
0.00 -> +0.05 -> +0.10 -> 0.00 -> -0.05 m/s
```

每个阶段包含足够的斜坡和稳态窗口。命令整形器限制速度变化率，禁止阶跃写入轮速或基座加速度。正式阈值作为配置字段进入测试，不能隐藏为脚本内魔数。

C1a 固定：

```text
v_y_cmd = 0
yaw_rate_cmd = 0
```

## Panda 轨迹坐标系

Panda 轨迹定义在 M1 机身坐标系。世界系期望位姿由当前或连续参考机身位姿与局部末端轨迹组合得到。因此 M1 前进时，Panda 仍在机身上方进行小幅摆动，不会为了保持世界坐标不变而持续向后伸展。

轨迹继续使用 C0 的连续、带限生成方法和同等级的小幅位置/姿态范围。安全 HOLD 或恢复后，以实测机身与末端状态重新定中心，禁止追赶过期目标。

世界系固定末端任务不进入 C1a。它将在 C2 中用于覆盖自适应底盘激活和更大范围运动再分配。

## 轮式接触模型

### 常量与顺序

- 轮半径：`0.095 m`；
- 四轮关节顺序沿用项目统一的 `M1_WHEEL_JOINT_NAMES`；
- 前进符号沿用当前已验证映射；
- C1a 启动 smoke 增加低速符号一致性校验，发现任一轮方向不一致则失败，不能自动掩盖配置错误。

### 约束

每个轮地接触在瞬时接触点施加：

- 法向非穿透和持续接触；
- 轮轴方向侧向无滑移；
- 滚动方向纯滚动关系；
- 正法向力；
- 摩擦锥；
- 广义动力学一致性。

接触点线速度由轮体 Jacobian、角速度和底部接触偏置共同计算。纯滚动关系将底盘纵向速度与轮角速度统一约束。名义轮速为：

```text
omega_cmd = v_x_cmd / 0.095
```

名义轮速只是低于平衡和接触的跟踪目标，不能覆盖硬约束。四轮轮速差异作为诊断和软均衡目标，不通过在 QP 外直接覆盖轮目标来修正。

## WBC 任务优先级

滚动 WBC 的硬约束包括：

1. 浮动基座与 23 个受控关节的完整动力学；
2. 四轮滚动接触运动学；
3. 正法向接触力和摩擦锥；
4. 广义加速度、关节速度、关节位置和执行器力矩限制；
5. 非有限值整批拒绝。

软目标按以下顺序设置权重：

1. 动态平衡、机身高度、横滚、俯仰和角速度；
2. 纵向底盘速度与轮速一致性；
3. 腿部支撑姿态；
4. Panda 关节和末端跟踪；
5. 接触力均衡、能耗和姿态正则。

若速度跟踪与平衡冲突，允许减速；若 Panda 跟踪与平衡冲突，允许缩放或暂停机械臂轨迹。

## Balance-first 安全监督

C1a 保留 C0 的安全状态名称，并扩展到底盘命令：

1. `TRACK`：正常跟踪底盘速度与 Panda 轨迹；
2. `SCALE`：底盘速度与 Panda twist 同时缩小到 50%；
3. `HOLD`：Panda 保持当前目标，底盘按限减速度平滑停车，禁止瞬间锁轮；
4. `RETRACT`：仅在实测纵向速度低于 `0.02 m/s` 后，Panda 才平滑收回安全弯曲姿态；
5. `TERMINATE`：持续失稳、非有限值或无法恢复时终止并锁存原因。

触发信号至少包括：横滚、俯仰、四轮接触数、侧向滑移、纯滚动残差、QP 可行性、关节/力矩限制和所有输入输出有限性。

非有限值直接进入终止路径。普通姿态或滑移告警使用连续样本计数和恢复迟滞，避免单帧噪声造成状态抖动。

## 诊断与输出

C1a JSON 摘要在 C0 字段基础上增加：

- 当前阶段和目标纵向速度；
- 实测纵向、横向速度；
- 纵向速度 RMSE；
- 分阶段位移和总位移；
- 停车收敛时间；
- 四轮目标与实测角速度；
- 最大轮速差；
- 最大纯滚动纵向残差；
- 最大侧向滑移；
- 轮力矩饱和计数；
- 各安全状态和原因计数；
- QP 可行率和最大等式/不等式残差；
- Panda 末端误差、最小奇异值和目标最大单步变化。

周期诊断必须能够区分命令整形、运动分配、QP、轮接触和安全监督中的失败来源。

## 验收门

正式 GPU0 验收运行 4000 个 mission steps，即 20 秒，不含启动 settling：

- 完成全部五个速度阶段；
- 纵向速度 RMSE `<= 0.03 m/s`；
- 停车命令后 1 秒内绝对纵向速度 `<= 0.02 m/s`；
- 前进阶段产生正位移，倒车阶段产生负位移；
- 最大纯滚动纵向残差 `<= 0.05 m/s`；
- 最大侧向滑移 `<= 0.05 m/s`；
- 四轮持续接触；
- 最大绝对横滚、俯仰均 `<= 10 deg`；
- Panda 最大末端位置误差 `<= 0.03 m`；
- QP 可行率 `>= 0.999`；
- `TRACK + SCALE` 占比 `>= 0.99`；
- `HOLD`、`RETRACT`、`TERMINATE` 计数均为零；
- 关节限制违反、机身触地、非有限值、机械臂目标跳变和意外 reset 均为零；
- `exit_reason == "steps_complete"`。

任一平衡、安全或接触门失败时，即使速度和末端误差达标，C1a 仍判定失败。

## 测试与执行顺序

实现遵循 TDD：先写失败测试，再写最小实现。

1. 轮半径、四轮顺序、方向和 `v/r` 映射单元测试；
2. 接触点 Jacobian、纯滚动、侧向无滑移和摩擦锥测试；
3. 速度时间表、斜坡和前进/停车/倒车阶段测试；
4. 机身坐标系轨迹变换与重定中心测试；
5. 滚动 WBC float64 QP 构造、可行性和失败诊断测试；
6. SCALE、平滑停车、静止后收臂和终止锁存测试；
7. C1a env、Gym ID、play 与 JSON 静态接线测试；
8. C0 全量回归；
9. GPU0 八步静态 smoke；
10. GPU0 关闭 Panda 运动的滚动基线；
11. GPU0 开启 Panda 运动的 4000 步正式验收。
