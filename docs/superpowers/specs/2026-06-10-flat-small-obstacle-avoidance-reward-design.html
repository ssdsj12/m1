Flat Small Obstacle Avoidance Reward 设计

日期：2026-06-10 ｜ 阶段：RL 配置 / 奖励设计 ｜ 目标配置： teacher_elevation_trajectory_mpc_semantic_flat_small_avoidance

1. 目标

新增一个专门用于平地小障碍物避障的强化学习配置，继承当前 TeacherElevationTrajectoryMpcSemanticEnvCfg，保持 observation/action 兼容， 以便从已有 checkpoint logs/rsl_rl/teacher_elevation_trajectory_mpc_semantic/2026-06-04_18-16-07 继续训练。

新增奖励只评价当前 IsaacLab 真实机器人姿态的 foot / shank(calf) / thigh 是否侵入语义小障碍 heightfield 风险区，不生成新的 foothold target，不修改 MPC reference，不修改 MPC loss。

核心边界： MPC 继续负责参考轨迹；新 reward 只负责给当前 policy 动作的腿部几何碰撞风险打分。

3. 奖励思想

奖励参考 MPC 中使用的 heightfield clearance 检测方式： 

deficit = relu(terrain_z + margin_part - point_z)
cost = deficit ** 2

区别是 MPC 检测的是规划轨迹或 FK 轨迹；新 reward 检测的是 IsaacLab 当前真实物理状态。 这样可以在真实 contact 发生前提供连续负反馈，同时避免和 MPC reference 争夺足端目标。

4. 地图锚点缓存

semantic_height_scanner 不是每个 policy step 都更新。为避免用旧地图时坐标错位，reward 维护一份地图锚点缓存： 

{
  "elevation_map": Tensor [N,H,W],
  "semantic_map": Tensor [N,H,W],
  "map_root_pos_w": Tensor [N,3],
  "map_root_yaw_w": Tensor [N],
  "last_signature": ...,
  "static_tensors": {
    "part_weights": Tensor [P],
    "part_margins": Tensor [P],
    "sample_alphas": Tensor [...]
  }
}

当 scanner map 更新时，缓存最新 elevation / semantic map，并同时记录当前 root position 和 root yaw。 当 scanner 没更新时，继续使用上一次 map 和上一次 root 锚点。当前 foot / shank / thigh 世界坐标点会先投影回缓存地图对应的 root frame，再查询缓存地图。

本设计不做 root 平移或 yaw 差的衰减门控；旧地图何时替换完全由 scanner 更新决定。

5. 当前 Curriculum 改造

本设计不新增另一套 curriculum。直接修改当前 terrain_levels_vel_semantic_plane_gate / row-based semantic obstacle curriculum 的 flat 语义 gate： 难度仍按 terrain row 推进，但 flat row 的通过条件改为 episode 级真实 small collision 成功率。

5.1 障碍数量和难度

flat small obstacle 数量参考 mpc_policy_eval.py --mode small_collision 的评估场景。 当前评估默认 --small-count-per-tile=80，并在 small_collision 模式中写入 plane_counts=(SemanticObstacleCount(small=80, large=0),)。 训练 curriculum 默认使用 10 个 row，逐步递增到 80： 

plane_counts = (
    SemanticObstacleCount(small=8, large=0),
    SemanticObstacleCount(small=16, large=0),
    SemanticObstacleCount(small=24, large=0),
    SemanticObstacleCount(small=32, large=0),
    SemanticObstacleCount(small=40, large=0),
    SemanticObstacleCount(small=48, large=0),
    SemanticObstacleCount(small=56, large=0),
    SemanticObstacleCount(small=64, large=0),
    SemanticObstacleCount(small=72, large=0),
    SemanticObstacleCount(small=80, large=0),
)

新 flat-small avoidance 配置只训练 flat；如果保留非 flat 表用于兼容，默认应为 SemanticObstacleCount(small=0, large=0)。

5.2 Episode 级语义 gate

当前 semantic gate 不再使用每 step 的 flat collision rate 作为升级指标。每个 env 在一个 episode 内维护： 

episode_had_small_collision[env]

每 step 用 IsaacLab 真实碰撞更新它： 

small_force = semantic_contact_small.data.force_matrix_w  # [N,B,F,3]
active = norm(small_force, dim=-1) > collision_force_threshold
episode_had_small_collision |= active.any(dim=(1, 2))

episode 结束时，只有完整走到 time_out 且本 episode 没有 small collision 的 flat env 才算成功： 

success =
    time_out
    and not episode_had_small_collision
    and not base_contact
    and not bad_orientation

curriculum 统计一个窗口内完成的 flat episodes： 

semantic_success_rate =
    successful_full_no_collision_episodes / completed_flat_episodes

满足 min_completed_episodes、success_rate_threshold，并连续 consecutive_success_required 个统计窗口通过后，flat row 才允许 move up。 非 flat terrain 的历史逻辑不作为本新配置目标；当前主线如仍保留非 flat，应避免被 flat-small gate 改坏。

6. 身体部件采样

为了并行性和稳定性，第一版直接读取 IsaacLab 的当前 body pose，而不是重复 MPC FK。

部件 来源 采样
foot robot.data.body_pos_w 中 .*_foot 每腿 1 点，shape [N,4,3]
shank / calf .*_calf body center 和对应 foot body center calf center 到 foot center 之间采样 S 点，shape [N,4,S,3]
thigh .*_thigh body center 和对应 calf body center thigh center 到 calf center 之间采样 T 点，shape [N,4,T,3]

这种方式用的是仿真 authoritative body pose，避免 joint order / FK 坐标约定风险，也减少每 step 重复计算。

7. 并行计算约束

  • 禁止 for env in range(num_envs) 形式的 per-env Python 循环。
  • 固定 part 数量允许 3 个分支，但查询和 reduce 必须 batch tensor 化。
  • 所有采样点合并成 all_points [N,P,3] 后一次性查询 height / semantic。
  • part_weights、part_margins、采样 alpha、semantic id tensor 按 device/dtype/sample_count 缓存复用。
  • 地图 clone 只在 scanner 更新时发生，不做每步全图比较。

9. Reward 合成

small_mask = semantic_id in small_semantic_ids
deficit = relu(terrain_z + margin_part - point_z)
point_cost = small_mask * deficit.square()

foot_cost  = reduce(foot points)
shank_cost = reduce(shank points)
thigh_cost = reduce(thigh points)
worst_cost = max(point_cost)

penalty = (
    foot_weight * foot_cost
  + shank_weight * shank_cost
  + thigh_weight * thigh_cost
  + worst_weight * worst_cost
)

reward = -clip(penalty, 0.0, penalty_clip)

初始建议：foot 惩罚低，shank/thigh 惩罚高。这样允许脚接近或跨过小障碍，但强烈惩罚腿部扫障碍。

12. 测试设计

12.1 纯 tensor 单元测试

  • 无 small semantic cell 时 penalty 为 0。
  • foot 点低于 small obstacle height + margin 时有惩罚。
  • shank/thigh 相同 deficit 的 penalty 高于 foot。
  • semantic id 为 ground 时不惩罚，即使高度接近。
  • 旧 map root 锚点下，当前 world point 能投影回缓存 map frame。

12.2 cfg 静态测试

  • 新 cfg 继承当前 MPC semantic cfg。
  • 新 cfg observation/action shape 不变。
  • 新 cfg terrain generator 只含 flat。
  • 新 cfg semantic curriculum flat small count 表为 8..80，large count 全为 0。
  • 新 reward 只挂到新 cfg，不影响现有 teacher_elevation_trajectory_mpc_semantic。

12.3 curriculum 单元测试

  • episode 内任意一步 semantic_contact_small 真实 force 超阈值后，episode_had_small_collision 保持 true 到 reset。
  • time_out=True 且无 small collision 计入成功 episode。
  • base_contact 或 bad_orientation 这类非 timeout termination 不计入成功。
  • 不足 min_completed_episodes 时 semantic gate 不通过。
  • 连续窗口成功次数达到 consecutive_success_required 后 flat row move-up 才放行。

12.4 IsaacLab smoke

  • 小规模 headless env 创建成功，reward 输出 shape 为 [num_envs]。
  • reward 无 NaN/Inf。
  • scanner 低频更新时，缓存只在更新步 clone map。
  • episode-level curriculum gate 使用 semantic_contact_small.data.force_matrix_w 真实碰撞，而不是 clearance reward 代理指标。
  • 用已有 checkpoint 跑短步数 play/train smoke，确认 observation/action 兼容。

13. 验收指标

  • 训练配置能从 2026-06-04_18-16-07 checkpoint resume。
  • flat-small 场景中 episode 级真实 small collision rate 下降。
  • curriculum 升级指标是完整 episode：不摔倒、不触发非 timeout termination、且无 semantic_contact_small 真实碰撞。
  • 速度跟踪不明显坍缩，策略不能靠原地不动逃避惩罚。
  • reward 计算不引入明显训练吞吐回退；4096 env 下需要记录 step timing。
  • 现有 MPC semantic 主线配置和 PLAY/VIEWER split 不回归。

14. 明确不做

  • 不参考 SemLoco 的 foothold target search，不新增另一套落脚点目标。
  • 不修改 MPC planner loss、command shaping、reference cache ABI。
  • 不在 reward 中调用 MPC plan_segment。
  • 不新增 root 位移或 yaw 差 gate；地图更新由 scanner 更新节奏决定。
  • 第一版不重复 MPC FK；直接读取 IsaacLab 当前 body pose。
  • 不新建另一套 curriculum；在当前 row-based semantic curriculum 上改 episode-level gate。
  • curriculum 不使用每 step 碰撞率作为升级指标。
