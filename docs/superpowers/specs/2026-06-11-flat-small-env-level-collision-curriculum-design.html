Flat-Small Env-Level 碰撞课程设计

日期：2026-06-11 ｜ 主线：T302q / T302r ｜ 范围： teacher_elevation_trajectory_mpc_semantic_flat_small_avoidance

一句话目标

把 flat-small 避障课程从“全局 semantic gate 放行”改成“每个环境在自己的 episode 结束时独立升降级”，并把 TensorBoard curriculum 指标收敛到一个核心值：mean_terrain_level。

新设计不再要求一批 reset 里同时完成足够多 episode，也不再用全局 gate 卡住所有环境。每个 env 自己完成一次 episode，就根据这个 episode 的真实结果决定自己的下一个 terrain level。

当前问题

问题 现象 后果
全局 gate 卡住升级 semantic_gate_pass=0，flat_move_up_count=0 单个 env 即使本 episode 走得够远、没有碰撞，也无法升级。
单次样本太少 completed_flat_episodes 大约 1 到 2，低于 min_completed_episodes=8 semantic_success_rate 被压成 0，指标像失败，其实是统计窗口不合理。
指标过多且误导 TensorBoard 有 success/gate/collision/count 多个 curriculum 标量 训练判断变复杂，且多个指标来自同一批不稳定统计。
clearance reward 太弱 新 run 中非零但 last-20 mean 约 -2.35e-7 信号存在，但 PPO 几乎感知不到，需要放大量级。

新课程原则

  • 课程升级/降级的基本单位是 一个 env 的一个完整 episode。
  • 只在这个 env episode 结束 / reset 时判断升降级，不按每个 step 升级。
  • 小障碍碰撞使用 sticky episode flag：episode 中任意 step 碰过一次，episode 结束时都算碰过。
  • flat env 的避障课程直接进入 env-level move_up / move_down，不再使用全局 semantic gate。
  • TensorBoard 的 curriculum 只保留 mean_terrain_level，和 IsaacLab 原版 terrain curriculum 风格保持一致。

Episode-End 流程

env_i episode 开始 ↓ 每个 step 更新 sticky flags: episode_had_small_collision_i episode_had_base_contact_i episode_had_bad_orientation_i ↓ env_i episode 结束 / reset ↓ 计算 distance_i 和 terrain_move_up_i / terrain_move_down_i ↓ 计算 episode_success_i ↓ 决定 move_up_i / move_down_i ↓ terrain.update_env_origins(env_ids, move_up, move_down) ↓ 清空 env_i sticky flags，进入下一个 episode

升级逻辑

基础距离条件

沿用 IsaacLab terrain curriculum 的核心判断：

distance_i = norm(root_xy_i - env_origin_xy_i) terrain_move_up_i = distance_i > terrain_size / 2

flat-small 成功条件

episode_success_i = time_out_i AND NOT episode_had_small_collision_i AND NOT episode_had_base_contact_i AND NOT episode_had_bad_orientation_i

flat env 升级

flat_move_up_i = terrain_move_up_i AND episode_success_i

含义是：这个环境本 episode 走得够远、正常结束、没有小障碍碰撞、没有 base contact、没有坏姿态，才让这个环境进入更高障碍数量的 row。

降级逻辑

基础距离降级

沿用原 terrain curriculum 的“走得太少降级”思想：

terrain_move_down_i = distance_i < norm(command_xy_i) * max_episode_length_s * 0.5 AND NOT terrain_move_up_i

推荐第一版降级

flat_move_down_i = terrain_move_down_i OR episode_had_base_contact_i OR episode_had_bad_orientation_i
第一版不建议让 small_collision 直接触发降级。小障碍碰撞应该先阻止升级；如果一碰就降级，早期探索会过于保守，环境容易反复掉回最低难度。

小障碍碰撞的第一版处理

if episode_had_small_collision_i: block move_up_i do not force move_down_i

后续可选开关

参数 推荐初值 含义
semantic_move_down_on_small_collision false 小障碍碰撞是否立即降级。第一版关闭。
semantic_move_down_on_base_contact true base contact 是否降级。建议开启，因为这是明显失败。
semantic_move_down_on_bad_orientation true 坏姿态 / 摔倒是否降级。建议开启。
semantic_move_up_requires_timeout true 是否必须正常 time out 结束才能升级。建议开启。

TensorBoard 策略

按用户要求，curriculum 只保留一个指标：

Curriculum/terrain_levels/mean_terrain_level

含义：所有 env 当前 terrain level 的平均值。它直接回答课程是否在推进。

不再从 curriculum 返回这些 TensorBoard 标量： plane_collision_rate、 completed_flat_episodes、 successful_full_no_collision_episodes、 semantic_success_rate、 consecutive_success_count、 semantic_gate_pass、 flat_move_up_count、 non_flat_move_up_count。

内部仍然保留必要状态用于判断升降级，但不把它们全部打到 TensorBoard。

奖励放大设计

当前 semantic_body_part_clearance 已经非零，但量级太小。新设计添加明确缩放参数：

semantic_body_part_clearance_scaled = semantic_body_part_clearance_raw * clearance_scale
参数 推荐初值 作用
clearance_scale 1000.0 把 1e-7 ~ 1e-6 量级提升到 PPO 更容易感知的范围。
penalty_clip 保留当前值 防止个别极端几何点导致过大惩罚。

正向影响

  • 机器人在真正接触 small obstacle 前就能收到负奖励。
  • 鼓励提前抬腿、避免 calf/thigh/base 贴近障碍。
  • 减少只靠 semantic_contact_collision 的事后稀疏惩罚学习。

风险

  • 当前 query radius 0.50m 和 margin 是 signal-first 参数，比较激进。
  • scale 太大会让策略过度害怕障碍，可能影响速度跟踪和步态。
  • 需要短训后检查 track_lin_vel_xy、mean_episode_length、semantic_contact_collision。

保留边界

  • 不改 observation shape。
  • 不改 action space。
  • 不改 MPC planner loss、reference cache、command shaping。
  • 不重新打开速度 curriculum。
  • 不把 raw/ 或 onlyReference/ 当作 active code。

验收方式

验收项 期望
curriculum TensorBoard 只保留 mean_terrain_level 作为课程指标。
课程推进 短训中 mean_terrain_level 不再长期塌在 0，能随 env-level 成功逐步上升。
稳定性 mean_episode_length 保持接近上限，base contact / bad orientation 不恶化。
语义避障 semantic_contact_collision 不上升，理想情况下随训练下降。
clearance reward 放大后保持稳定非零，但不能压坏速度跟踪。

实现顺序

  1. 新增/调整测试，覆盖 env-level episode 成功升级、small collision 阻止升级、base/bad 降级。
  2. 把当前全局 semantic gate 移除出 move_up 路径。
  3. 在 episode sticky flag 中记录 small collision、base contact、bad orientation。
  4. 修改 flat env 的 move_up / move_down 公式。
  5. 精简 curriculum return，只保留 mean_terrain_level。
  6. 添加 clearance reward scale，并用短训验证量级。
  7. 更新 notes/todo/log，记录行为变化和验证结果。
